# 🚀 Cocolously Optimized

[![Modrinth](https://img.shields.io/badge/Modrinth-Cocolously--Optimized-green?logo=modrinth)](https://modrinth.com)
[![Minecraft](https://img.shields.io/badge/Minecraft-Fabric-blue?logo=minecraft)](https://fabricmc.net)

**Cocolously Optimized** is a performance-focused Minecraft modpack based on Fabric. It is a custom fork of [Fabulously Optimized](https://github.com/Fabulously-Optimized/fabulously-optimized), designed to maximize FPS and stability while maintaining 100% Vanilla gameplay parity.

---

## ⚡ Features

- **Maximum Performance:** High FPS gains and stutter-free gameplay powered by Sodium, Lithium, Indium, and modern rendering tweaks.
- **Shader & Resource Pack Support:** Native shader support via Iris alongside full compatibility with custom OptiFine features (Connected Textures, Custom Item Models, etc.).
- **Pure Vanilla Compatibility:** No gameplay mechanics are altered. Fully safe and compliant for public multiplayer servers.
- **Fast Startup:** Lightweight footprint optimized for both high-end gaming setups and low-end hardware.

---

## 🛠️ Installation

### Modrinth App (Recommended)
1. Download and install the [Modrinth App](https://modrinth.com/app).
2. Search for `Cocolously Optimized` in the app's search bar.
3. Click **Install** and hit **Play**.

### Third-Party Launchers (Prism Launcher, MultiMC, etc.)
1. Download the latest `.mrpack` file from the **Releases** section on GitHub or Modrinth.
2. Open your launcher and select **Add Instance** -> **Import from zip/mrpack**.
3. Select the downloaded file and launch the game.
